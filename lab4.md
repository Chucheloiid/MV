# 1. Постановка задачи

Рассматривается задача Коши

```math
u'=\frac{u^2\ln x-u}{x},
\quad x\in[1,2]
```

с начальным условием

```math
u(1)=0.5
```

Точное решение задачи имеет вид

```math
u(x)=\frac{1}{\ln x+x+1}
```

Требуется найти численное решение на равномерной сетке с шагами

```math
h=0.1
```

и

```math
h/2=0.05
```

с использованием неявного метода трапеций.

Для решения нелинейного уравнения, возникающего на каждом шаге метода трапеций, необходимо использовать метод Ньютона.

Требуется:

* получить численное решение задачи Коши;
* вычислить максимальную абсолютную ошибку относительно точного решения;
* выполнить оценку погрешности по правилу Рунге;
* построить графики точного и численного решений;
* сравнить полученные результаты.

# 2. Теоретические сведения

## 2.1 Неявный метод трапеций

Для дифференциального уравнения

```math
u'=f(x,u)
```

неявный метод трапеций записывается следующим образом:

```math
y_{i+1}
=
y_i+
\frac{h}{2}
\Bigl(
f(x_i,y_i)
+
f(x_{i+1},y_{i+1})
\Bigr)
```

Значение

```math
y_{i+1}
```

входит в обе части формулы, поэтому метод относится к неявным.

Порядок точности метода:

```math
p=2
```

Следовательно, при уменьшении шага сетки в два раза погрешность должна уменьшаться примерно в четыре раза.

---

## 2.2 Метод Ньютона

Для нахождения значения

```math
y_{i+1}
```

необходимо решить нелинейное уравнение

```math
F(y)=0
```

где

```math
F(y)
=
y-y_i
-
\frac{h}{2}
\Bigl(
f(x_i,y_i)
+
f(x_{i+1},y)
\Bigr)
```

Для решения используется метод Ньютона:

```math
y^{(k+1)}
=
y^{(k)}
-
\frac{F(y^{(k)})}
     {F'(y^{(k)})}
```

Итерационный процесс продолжается до достижения заданной точности.

---

## 2.3 Оценка погрешности по правилу Рунге

Для метода порядка

```math
p
```

оценка погрешности вычисляется по формуле

```math
R=
\frac{|y_h-y_{h/2}|}
     {2^p-1}
```

Для метода трапеций

```math
p=2
```

поэтому

```math
R=
\frac{|y_h-y_{h/2}|}
     {3}
```

Максимальное значение вычисляется по всем узлам сетки.

# 5. Анализ результатов

При уменьшении шага сетки в два раза максимальная ошибка уменьшилась приблизительно в 4.8 раза:

```math
\frac{8.2580\cdot10^{-4}}
     {1.7079\cdot10^{-4}}
\approx 4.83
```

Полученный результат близок к теоретическому значению

```math
2^2=4
```

что подтверждает второй порядок точности метода трапеций.

Оценка погрешности по правилу Рунге практически совпадает с фактической ошибкой решения на более точной сетке, что свидетельствует о корректной реализации алгоритма.
